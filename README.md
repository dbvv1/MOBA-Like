# MOBA-Like

开发中的原创网页 MOBA：操控一名英雄与机器人对战，沿兵线推进并摧毁对方基地。设计目标见 [docs/brief.md](docs/brief.md)。

## 运行

需要 Node.js 22.12 或更新版本，以及支持 WebGL 2 的桌面浏览器。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。若页面提示 WebGL 2 不可用，需要使用支持它的浏览器与图形环境。

构建并预览网页版本：

```sh
npm run build:web
npm run preview:web
```

网页产物在 `web-dist/`；`npm run build` 单独构建无画面模拟工具，输出到 `dist/`。

## 离线组队候选

在地址后加 `?match=offline-5v5` 开启单线离线 5v5：你控制蓝方第一名英雄，另有 4 名队友机器人和 5 名敌方机器人；Veyra 与 Morrow 交错编组。沿兵线推塔、摧毁基地结束，Restart 以当前英雄选择重开。可用 `&seed=72` 固定另一组机器人决策种子。不加参数仍是原来的 1v1；不包含联网。

## 操作

- **Next match hero → Restart**：选择 Veyra 或 Morrow 后开启新局；更改选择不会修改当前对局，直接 Restart 保留上次选择。Morrow 的 W 为立即施放的自身护盾，Q 为方向弹道，E/R 为地面技能；技能名与操作提示随英雄切换。默认 1v1 的对手仍为 Veyra。

- **右键敌人**：指定目标，追入射程后普攻；不是攻击命中保证。
- **右键地面／友方单位**：移动；点无敌敌方建筑不会自动走进其脚下。
- **Q / W / E / R** 或技能按钮：选择技能，再左键地面或敌人施放；自身技能立即施放。
- **A，再左键地面**：攻击移动，沿途自动获取敌人。
- **S**：停止当前移动或攻击指令；**Esc**：取消瞄准。
- **Space**：锁定镜头到英雄；取消 HUD 的 **Lock camera** 后，把指针移到画面边缘移动镜头。
- **装备按钮**：花费金币购买；技能和购买是否合法由对局规则决定。
- **Restart**：重新开局。切到后台标签页时对局暂停。

界面显示生命、法力、等级、金币与技能冷却；阵亡后等待复活，基地被摧毁后结束对局。

## 无画面对局

```sh
npm ci
npm run sim -- --games 200 --seed 1
npm test
npm run build
```

`sim` 与网页新对局采用 v10 规则，小兵接战时会彼此让出有限空间。可用 `--content-version 1`、`2`、`7` 或 `8` 运行旧规则，或用 `--content-version 9` 比较分阶段单位结算。回放记录自身版本，不随默认值改变。
