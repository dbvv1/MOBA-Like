# 连续地面分区作者试用

当前未采用。目标是让出生地、塔前和兵线形成连续空间，而非在原直条旁增加摆件。原导航、碰撞、建筑/单位位置与镜头全部不变；林地仍可通行，土路不是新的导航边界。

- `source/layout.json`：基地主体与塔前留地、约7m主行进带、非规则边缘；与正式地图建筑坐标对齐。
- `source/*-albedo-source.png`：内置 image_gen 原创建图原件，实际1254²；不是CC0，也不是开放权重推理。完整prompt/时间/原边沿检查保留。
- `export.py`：仅RGB、Lanczos到1024²、WebP90，未改色/重绘/修缝；导出manifest保存原件与运行件SHA。
- 运行时世界XZ重复UV（路10m/林地12m），sRGB albedo、roughness1、metalness0，沿原灯光。没有新增法线/粗糙度图或PBR渲染架构。
- 两纹理属于当前world，地面及路边贴片只借用；任何纹理加载失败释放已取得部分并用原平色地面，重开统一释放。

现成源比较：已持有的KayKit Medieval Hexagon道路/草地模块与建筑同源，但原件厚六角边和规则路口不直接适合连续MOBA战场；Kenney Nature Kit单个树石替换已在真实整屏失败。生成纹理只是候选供给，Repeat接缝、噪声/模型一致性和实际场地段落须正常镜头决定，不按成功生成或CPU检查采用。

运行供给为两张1024² WebP，共574,792字节（约575KB）；按RGBA8上传且含完整mip链估算约10.67MiB纹理内存，这不是浏览器实测GPU占用。纹理只设置sRGB/Repeat/线性mip和4级anisotropy，实际GPU上限由Three/设备控制。原件边沿差值检查仅诊断，不等于Repeat无缝。

当前13项局部测试与web构建通过；首次正常浏览器观察在导航阶段Page crashed，0帧，因果未确定。尚无采用后的实际材质画面，不作地面品质提升结论；原地图与已发布9311保持不变。
