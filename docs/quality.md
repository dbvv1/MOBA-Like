# 一次基本战斗：直接指定普攻目标

## 参照与本轮画面

主参照为英雄联盟的点选战斗：玩家选择敌人，角色按自己的射程追击与攻击，改点地面后移动。[Riot 的 Zeri 设计说明](https://www.leagueoflegends.com/en-gb/news/game-updates/champion-insights-zeri/)把普通右键普攻与需要瞄准的技能射击区分开；本例复用既有命令与技能体系，不复制英雄机制。参照并排图只保留本地。

2026-10-26，固定源 `57f8eaf`，Morrow 正常跟随兵线并使用 W，右键当前可见敌兵，再点空地、停止并打开帮助。两帧来自同一段连续操作的 tick 858／899，不是同帧 A/B。测试归档只添加逐逻辑步的有界只读事件观察；它记录了 tick 848 的真实 `basicAttack`，没有改变模拟或画面。

## 本轮改变

- 右键可攻击敌方提交已有 Attack，明确指定那个对象；不再只能先走到点击处、依赖 A 的自动获取。
- 右键地面或友方继续移动，并取消当前技能瞄准；点无效或不可攻击敌人不会偷偷变成走向其脚下。
- 既有目标括号回答“当前攻击／追击谁”，不代表必中。对方离开射程仍须追击，点地面与 S 可以停止；菜单不把点击透传给世界。

正常片段已实际覆盖指定敌兵、真实出手、点地移动与菜单隔离；另一次点敌英雄后持续追击，但对方退跑，没有据此宣称必能追上。原模拟版本与即时结算保持，默认仍为 10。

## 最大差距与下一步

1. **密集目标仍需要精确点选**：小兵轮廓与细血条在群中容易重叠；有明确命令入口，不等于所有拥挤局面都能轻松指中。
2. **出手与受击主次仍弱**：角色准备、释放和命中关联尚不如参照清楚；不能靠当前目标括号代替敌方出手提示或命中确认。
3. **场景与声音仍待提高**：宽直平涂道路缺少层次；既有声音尚缺实际主观听验。
