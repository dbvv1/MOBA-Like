# 塔前灯光：GPU 对照拒收当前改动

**不采用灯光候选 `069b74b`，不换默认。** 非作者只看同机位 GPU 实帧与 AI 方向图，盲选改前 `baecaf5`，优势小但明确：改后塔身更暗，黑硬投影抢眼，损害可读性。此前软件实帧的小幅收益未在这组 GPU 对照中成立；两版都远未达到目标。

## 改动与成本

- 用 CC0 HDRI 经 PMREM 提供天空填光；加载时分离日盘，由单一方向光负责可遮挡的日照，避免太阳能量同时变成无阴影填光。原 HDR 文件保留，配方与许可见[灯光素材说明](../assets/lighting/README.md)。
- 保同一相机、模型、底色和玩法，接入局部接触 AO、固定 ACES 输出与同色系天空／远雾；不靠继续抬亮或加重 AO。
- HUD 与技能提示不参与 AO；保留原有深度测试／写入、色调映射和透明混合，需要深度测试的提示仍按实际世界深度遮挡。

这组实帧的提交量从 **296 → 455 draw calls、90,968 → 155,269 三角形**；额外成本主要来自 AO 法线／深度 pass，尚无帧时间结论。

## 最大差距

1. **受光层次不足**：两版仍是大块均匀底色，缺少目标图中的暖亮受光面、冷色阴影与地面明暗变化。
2. **投影和接地不自然**：改后的黑硬投影压过表面细节；改前较温和，但单位脚边仍缺清楚的落地关系。
3. **单位与标记层级弱**：兵群身体、武器和血条重叠；仅凭这一帧不能可靠认出玩家英雄，也不能确认粉色圆圈的效果含义。

下一轮换手段解决受光与角色层级，不在这套灯光上继续调参。静态拒收不代表操控、声音或完整对局已验；拍摄重复性仍失败，安全与清理回执待补。旧软件帧与本批状态不同，跨环境差异原因未明，不混作同状态比较。
